# Analyst pilot kit (VALUE-05)

Prepared 2026-10-30. **No real pilot has run.** Everything measured so far is an agent rehearsal
([`evidence/value-05-pilot-rehearsal-20261030.md`](../evidence/value-05-pilot-rehearsal-20261030.md)), recorded in the
app as `rehearsal` and kept out of real pilot results. VALUE-05 stays open until the owner's analysts record real
measurements.

| File | For | What it is |
|---|---|---|
| [01-pilot-plan.md](01-pilot-plan.md) | Owner | One page: goals, timeline, people, success measures and what counts as failure |
| [02-task-cards.md](02-task-cards.md) | Analysts, coordinator | 12 task cards on the demo workspaces, with timing rules and what "correct" means |
| [03-timing-sheet.csv](03-timing-sheet.csv) | Analysts, coordinator | One row per card and analyst; every scorecard field has exactly one column |
| [04-observation-form.md](04-observation-form.md) | Analysts | The same fields as a form to fill by hand, with the app's labels |
| [05-invite-and-briefing.md](05-invite-and-briefing.md) | Analysts | Invitation and day-one briefing in plain business language |
| [06-checkins-and-review.md](06-checkins-and-review.md) | Coordinator | 15-minute daily check-in and the end-of-pilot review agenda |
| [07-data-and-privacy.md](07-data-and-privacy.md) | Owner, analysts | Which data, who sees what, model use limited to low-cost models |
| [08-answer-key.md](08-answer-key.md) | Coordinator and reviewer only | Reference queries and rehearsal values for checking correctness. Do not share with analysts |

Where it lives in the app: **Overview → Pilot scorecard** records an assessment (turn on **Show expert tools** at the
bottom of the menu first); **Settings → Members & policy → Pilot readiness** shows workspace owners what the pilot
still lacks. The scorecard records investigations, Ask
conversations, dashboards and reports made by conversation, and scheduled digests, and splits results by feature.
